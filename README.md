# 中国股指左侧交易策略回测仪表盘

基于 Streamlit 的交互式回测工具，专注于中国主要股指（沪深300、中证500、中证1000、上证50、创业板指）的左侧交易（越跌越买 + 分批卖出）策略。

## 功能

- 实时调节 RSI 入场/加仓/分批卖出/清仓阈值，立即看到回测结果与图表
- 支持布林带下轨共振过滤、MACD 共振过滤
- K线 + 布林带、RSI、MACD、权益曲线四联图
- 可选参数组合扫描与排名
- 数据来自 akshare

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 策略逻辑

- **越跌越买**：RSI 低于入场阈值建仓，更低时继续加仓（分层）
- **分批卖出**：RSI 升至减仓阈值时逐层卖出，更高时全部清仓
- 可叠加布林带（价格接近下轨）与 MACD 作为买入共振条件

仅供研究与学习，不构成投资建议。
